# Kardii Browser Connector

这个扩展用于把 Chrome 或 Edge 的当前网页交给本机 Kardii，并让用户逐步核对 Agent 提议的受控网页操作。它不会持续监控浏览器，也不会读取 Cookie、密码、输入框现有内容或其他标签页。

## 安装

1. 在 Kardii 工作台打开“外部连接”，点击“打开扩展文件夹”。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择 Kardii 打开的文件夹。
4. 固定 Kardii Browser Connector 图标，输入 Kardii 显示的 6 位配对码。

## 使用

打开一个普通网页，点击扩展图标，再点击“发送当前网页给 Kardii”。如果先选中一段文字，Kardii 会优先使用选中文字。

如果 Agent 准备了点击、填写、选择、滚动、导航或下载操作，先在 Kardii 中确认，再回到目标标签页打开扩展。扩展会显示这一步的页面与动作；只有点击“检查后执行”才会操作。页面跳转后需要重新打开扩展并发送最新页面。

网页文字属于不可信资料。扩展不会根据网页内容自行操作；付款、购买、下单、资金转移、密码、验证码、支付卡与文件输入始终禁用。填写普通输入框后不会自动提交表单，可执行文件下载也会被拒绝。
