# Kardii AI Companion

Kardii 是一个使用 Tauri 2 制作的跨平台透明悬浮桌宠与 AI 聊天伙伴。

## v2.1 手机企微远程 Agent

- 工作台「外部连接 → 企业微信」新增默认关闭的“手机远程 Agent”。绑定码只能在电脑端生成，10 分钟过期且使用一次后立即失效；同一台 Kardii 只接受一个绑定企微账号的私聊命令
- 普通企微聊天与远程任务完全分流。绑定账号私聊既可显式发送 `/任务 目标`，也可直接说“把我电脑上的报价单.xlsx 发给我”；后者只由本地固定规则识别包含电脑或授权目录以及明确发送、查找、读取动作的文件请求。两种方式都只生成 5 分钟有效的待确认草稿，核对目标与权限范围并发送一次性 `/确认` 后才会进入 Agent。群聊、未绑定账号和其他自然语言仍只聊天
- 远程白名单始终包含公开网页搜索，并可由用户在电脑端分别开启“Kardii 知识库只读”“企微文档只读”、预先选择的授权目录只读，以及逐项勾选的只读 MCP 工具。另有独立关闭的“向绑定账号发送单个指定文件”权限；开启后每个已确认任务最多回传一个授权目录中的明确文件或 PNG/JPG 图片，禁止整个目录、批量文件、压缩包、可执行文件和未授权文件。MCP 每次调用前仍会重新获取工具清单并验证只读；私人长期记忆、未授权文件、剪贴板、桌面浏览器、终端和所有外部写入均拒绝执行
- 任务完成、失败或需要补充信息时会回到企微；可使用 `/回答 任务码 内容` 继续，也可通过 `/状态`、`/授权`、`/结果 任务码` 与 `/取消 任务码` 查询、查看脱敏授权名、取回或停止任务
- 绑定用户可以在电脑端同时开启文件回传后，从企业微信私聊发送 `/任务 在授权目录中找到某个文件并发给我`，或直接说“把我电脑上的某个文件发给我”，再发送一次性 `/确认`；Kardii 会先搜索、再校验真实相对路径，电脑无人值守时自动通过企微媒体接口回传。自然语言只创建待确认草稿，文件发送权限不会通过普通聊天、群聊或未确认消息自动获得
- 企微可接收图片及支持的文档附件并交给普通聊天或显式远程任务处理；较长的 `/结果` 会以 Markdown 文件返回。附件通过企业微信官方加密下载和媒体上传协议传输，并继续作为不可信资料处理
- Agent 仍在本机运行并使用企微专用模型；绑定用户可发送 `/模型` 查看选项，或用 `/模型 自动`、`/模型 DeepSeek`、`/模型 Codex` 等切换电脑端已经配置好的模型。自动模式以本地固定规则按图片、复杂任务或短问答选型，不额外调用模型做路由，并会在回复中标明实际模型。电脑必须保持联网、未休眠且 Kardii 留在托盘
- 在电脑端关闭远程 Agent、解除绑定或更换读取范围后，Agent 窗口会立即应用新范围；解除绑定会安全停止尚未结束的远程任务

## v2.0.1 企业微信聊天加速

- 企业微信机器人收到文字或已转写语音后会先立即显示“Kardii 正在思考…”，不再等整段回答生成完才出现反馈
- 回答生成期间复用同一个企业微信流式消息 ID，每隔约 350 毫秒发送一次累计内容，完成后再标记结束，避免刷出多条零碎消息
- 工作台可为企业微信单独选择模型；既可跟随桌面聊天，也可指定 Gemini、DeepSeek、Codex 或当前 Ollama 模型
- 新增“快速”和“完整”两种回复模式：快速模式使用最近 6 条历史与较短回答额度，完整模式使用最近 12 条历史并保留更多细节
- 普通聊天的安全边界不变：不同 Bot、单聊与群聊继续隔离，不加载桌面私人长期记忆，也不会因自然语言自动执行 Agent；v2.1 的显式远程任务通道另行绑定、二次确认并受只读白名单约束

## v2.0 企业微信连接

- 工作台「外部连接」新增企业微信卡片。文档账号通过企业微信扫码授权，不要求把日常登录密码交给 Kardii
- 文档扫码授权与 API 模式智能机器人是两个独立连接：前者决定可访问哪些企微文档，后者只负责把企微消息送到本机 Kardii
- 正式构建会下载企业微信官方 [`wecom-cli` v1.1.0](https://github.com/WecomTeam/wecom-cli)，按固定 SHA-512 完整性值校验后把对应平台的独立二进制放入安装包；运行 Kardii 不依赖用户另装 Node.js
- 文档搜索只返回当前扫码账号本来就有权访问的内容。因此，大圆或同事创建并分享给当前账号的文档可以搜索和读取；未分享的私有文档以及大圆自己的私有记忆无法读取
- 支持搜索企微文档，并读取在线文档 `doc` 与智能文档 `smartpage`；多个搜索结果必须由用户明确选择，Kardii 不会按相似标题擅自猜测
- 新文档默认创建为智能文档。在线文档和智能文档都支持追加或覆盖；修改前会重新读取最新内容，创建、追加与覆盖每次都显示目标和内容预览并单独确认
- 智能文档有多个页面时必须明确选择页面；`b1_` 发布态智能文档保持只读，修改时需使用企业微信中的编辑态文档
- Agent 新增 `wecom_document` 工具：搜索与读取可自动执行，创建、追加和覆盖不能纳入永久授权或后台静默执行
- 可连接企业微信「API 模式」智能机器人，在企业微信单聊或群聊中直接使用 Kardii AI；既可跟随桌面模型，也可指定企微专用模型，不同 Bot、单聊与群聊使用隔离的本机会话历史，并可在工作台一键清空
- 机器人 Bot Secret 只进入 Windows 凭据管理器或 macOS 钥匙串，不写入工作台、SQLite、JSON 备份或日志
- 企微普通聊天处理文字、已经转写成文字的语音、图片和支持的文档附件。机器人保留 Kardii 的性格，但不会带入桌面端的私人长期记忆或自定义指令；普通自然语言不执行 Agent 或外部写入。v2.1 只有绑定本人、显式命令与二次确认齐全时才创建安全只读远程任务

### 连接方法

1. 打开 Kardii 工作台，进入「外部连接」→「企业微信连接」，点击「扫码连接」，用企业微信完成文档授权。
2. 授权后输入标题或正文关键词搜索；选择明确文档，再读取、追加或覆盖。也可以在桌面聊天里把要求交给 Agent。
3. 若要在企业微信里聊天，先按[企业微信官方说明](https://open.work.weixin.qq.com/help2/pc/cat?doc_id=21677)创建 API 模式智能机器人，将 Bot ID 与 Secret 填入 Kardii 并点击「保存并连接」。
4. Kardii 必须保持运行（可以隐藏到系统托盘），机器人长连接才会接收消息；完全退出 Kardii 后不会在云端继续回复。
5. 如需手机远程任务，在电脑端打开“手机远程 Agent”，生成绑定码并到机器人私聊发送 `/绑定 绑定码`。需要读取本机资料时，用“选择目录”登记最多 8 个只读目录；需要 MCP 时，只勾选已经测试成功且服务器明确标记为只读的具体工具。
6. 在企微私聊发送 `/任务 目标`，或直接发送包含电脑文件与明确动作的句子，例如“把我电脑上的报价单.xlsx 发给我”。核对机器人返回的目标和允许范围，再发送 `/确认`。发送 `/模型` 可查看或切换企微专用模型，发送 `/帮助` 可查看全部命令。

## v1.9 多 Agent 并行与后台自动化

- 最多同时运行 3 个 Agent 任务；每个任务分别保存目标、计划、技能快照、来源聊天、工具结果和授权状态，不会把不同任务的上下文拼在一起
- 第 4 个及之后的任务会按进入队列的时间等待；任一 Agent 完成、暂停、失败或等待用户后，队列中的下一个任务自动获得空闲席位
- Agent 窗口关闭时只会隐藏，正在进行的只读步骤仍会继续；标题栏和任务列表会显示当前并行数、排队数与负责该任务的 Agent 席位
- Rust 后台调度器每 30 秒唤醒隐藏的 Agent 窗口检查自动化，避免单纯依赖隐藏 WebView 的计时器；启动时会为已经到期的每条自动化最多补建一次任务
- 后台任务需要权限、需要回答、完成、失败或进入队列时，桌宠上方会出现主题一致的提醒；点击提醒直接打开并定位对应任务
- MCP 明确标注的只读工具和无需权限的分析步骤可以在后台继续；文件、剪贴板、浏览器、终端以及未知、写入或删除类 MCP 操作仍按原规则暂停确认
- 浏览器操作仍需 Kardii 与扩展内两次确认；付款、购买、下单、资金转移、密码、验证码和支付卡操作继续永久禁止
- 后台执行依赖 Kardii 进程留在系统托盘；完全退出、电脑关机或休眠时不会执行，也没有云端服务器代替用户电脑运行

## v1.8 SQLite 本机数据与恢复

- 聊天会话、AI 与语音设置、个性和长期记忆、工作台、Agent 任务、技能、自动化以及本机操作日志会同步写入应用数据目录中的 SQLite 数据库
- 首次升级会自动读取现有 WebView 本机数据并迁移到 SQLite；启动时先从数据库恢复再加载页面，不需要重新建立会话、关系、项目或设置
- WebView 本机存储继续作为运行缓存与旧版兼容层；每次增删会排队镜像到 SQLite，正常退出前会等待尚未完成的写入
- 数据库使用 WAL、外键和 `quick_check` 完整性检查；每个已修改的数据键最多保留 10 条旧值修订，总修订记录限制为 1000 条
- 有数据时每天首次启动最多自动建立一次 SQLite 恢复点，也可以在齿轮的“本机数据”中手动建立；只保留最近 5 个，避免无限占用硬盘
- 恢复最近一次数据前会先自动保存当前数据库；恢复后再次运行完整性检查，失败时自动退回恢复前状态，然后重新载入 Kardii 的所有窗口
- API Key、邮箱密码、OAuth / Codex 登录令牌、浏览器配对凭据等敏感信息不会写入 SQLite，仍只保存在 Windows 凭据管理器或 macOS 钥匙串
- SQLite 恢复点用于同一台电脑上的快速回退；跨电脑迁移继续使用完整 JSON 备份，原始知识库文件仍需单独复制

## v1.7 企业资料联合分析与多网页知识库

### 企业资料联合分析

- 工作台新增“联合分析”，可按项目、关系对象以及最近 7 / 30 / 90 天或全部时间限定范围
- 可组合项目与关系、待办与活动、工作记录和成果、IMAP 邮件摘要、Google / Microsoft 云端概览、知识库与网站快照，以及当前独立聊天会话
- 每个输入来源使用稳定的 `[S1]` 编号；模型必须为可核验事实、数字、日期和承诺标注来源，并把推断、建议、冲突与资料缺失分开说明
- 输出包含综合摘要、进展、承诺与负责人/日期、风险与阻塞、下一步、今日简报以及来源说明；结果先作为可编辑草稿，人工确认后才保存
- 已保存分析保留来源标题、时间与公开链接，网页或云端来源可直接打开核对；下一步可按行转成 Kardii 今日待办
- 可开启每日简报提醒并指定时间。提醒只在 Kardii 正在运行或下次打开时建立一条本机待办，不会在后台读取、上传或发送企业资料
- 邮件来源只使用已同步的主题、发件人、正文摘要和附件名；云端来源只使用只读概览，不会声称已经读取未归档的附件或云端文件全文

### 整站与多网页知识库

- 知识库新增“导入网站”：填写公开起始网址，选择最多 5 / 10 / 20 页与 0–2 层链接深度，确认有权读取后先预览抓取结果
- 只抓取公开 HTTP(S) 页面并跟随同域链接；拒绝 localhost、内网、保留 IP、跨域重定向、非网页内容和带用户名/密码的网址
- 域名解析结果在请求前检查并固定到已验证的公开地址，手动检查重定向；单页最大约 1.5 MB、单次最多约 120 万字、整次预览最多约 90 秒，并对失败页面单独显示原因
- 读取站点 `robots.txt` 的基础 `User-agent` / `Disallow` 规则；不使用浏览器 Cookie、不执行网页 JavaScript、不填写表单，也不访问登录态、付费墙或个人账号页面
- 页面标题、原网址、抓取深度、文字快照和告警先在主题弹窗中展示，可逐页取消不需要的结果，只有再次确认才保存
- 保存后每个网站形成一个可更新的集合；可重新抓取替换旧快照，或一次删除集合及其页面。页面自动参与现有知识库检索和 `[K]` 来源问答

## v1.6.1 多会话与 Agent 任务连续性

- 聊天窗口新增会话列表和“新对话”，最多保留 30 个独立话题；第一条用户消息会自动生成简短标题
- 每个会话分别保存聊天历史、未发送草稿、Codex 线程和关联 Agent 任务，不再把不相关话题混进同一个上下文
- 切回旧会话会恢复原来的内容；旧版单一聊天历史首次启动时自动迁移为一个会话，不会清空数据
- 同一会话再次进入 Agent 时会优先继续原任务：已完成、失败或暂停的任务保留上一轮结果并重新规划，等待回答的任务可直接从聊天续上
- Agent 正在运行或等待授权时不会创建重复任务，而是定位到原任务；Agent 页面会显示来源聊天会话
- 普通聊天会读取当前会话关联 Agent 的状态、问题与最近结果；其他会话的 Agent 内容不会带入
- 完整 JSON 备份新增全部聊天会话与关联关系；爱心中的个性和长期记忆仍是所有会话共用的全局设置

## v1.6 受控浏览器与 Agent MCP

### 受控浏览器操作

- 浏览器扩展发送网页时会标记当前页可见的链接、按钮、普通输入框、下拉框和选择项，Agent 先用 `browser_read` 获取文字与目标 ID
- Agent 可以提出点击、填写、选择、滚动、导航和下载；每一步先在 Kardii 主题权限卡中确认，再由用户打开扩展核对当前网页与动作并点击“检查后执行”
- 扩展继续只使用 `activeTab`、`scripting` 与固定回环桥接权限，不申请 `<all_urls>`、Cookie、下载管理或后台标签页权限；跨站跳转后需要重新打开扩展并发送页面
- 填写只支持普通输入框，不自动提交表单；密码、验证码、Token、支付卡、文件输入框，以及付款、购买、下单和资金转移操作在 Rust 后端与扩展脚本中双重禁用
- 下载只允许当前页已有的 HTTP(S) 链接，并拒绝 EXE、MSI、DMG、PKG、脚本等可执行文件类型；实际文件仍由浏览器下载栏交给用户检查

### Agent 使用 MCP

- Agent 会读取工作台中已经测试成功的 MCP 工具清单与输入 schema；服务器明确标注 `readOnlyHint` 的工具可自动调用
- 未证明只读、可能写入或删除的工具每次都暂停确认，不能被“允许本任务执行”跳过；付款、购买、下单和资金转移类工具始终禁用
- Rust 后端在每次调用前重新执行 `tools/list` 并再次核对工具风险；含密码、Token、API Key、验证码或支付卡字段的参数不会发给第三方 MCP
- Agent MCP 日志只保存服务器、工具名、成功状态、耗时与错误摘要，不保存完整参数、结果或凭据

## v1.5.1 全类型附件、OCR 与长文档

- 普通聊天与 Agent 回答附件统一支持 PDF、DOCX、PPTX、XLSX、CSV、TXT、Markdown、JSON、PNG、JPG 和 WebP，一次最多 6 个
- PDF 与 Office 文字继续先在本机解析；扫描 PDF、普通图片以及 DOCX / PPTX / XLSX 内嵌图片可在用户主动上传后交给 Gemini 识别
- 工作台导入预览会标出需要视觉识别的文件，并提供“识别扫描件 / 图片”按钮；OCR 结果可在保存和综合分析前人工检查
- 长文档会按当前问题切成重叠片段并进行相关性排序，不再只把开头固定字数交给模型
- 单个聊天附件上限 20 MB、单张图片上限 8 MB；本轮视觉识别总量上限 20 MB。非 Gemini 模型只使用可在本机提取的文字，不猜测扫描页或图片内容

## v1.5 浏览器与 MCP 连接

### Chrome / Edge 当前网页

- 工作台“外部连接”可以启动只监听 `127.0.0.1:43198` 的本机浏览器桥接，并显示 6 位配对码
- 安装包内附 Manifest V3 扩展；在 Chrome 或 Edge 的扩展页选择“加载已解压的扩展程序”即可安装
- 扩展使用 `activeTab`：只有点击扩展图标时才读取当前标签页，并可优先发送用户选中的文字
- 页面快照可交给普通聊天、建立 Agent 任务或保存到知识库；知识库会保留原网址与发送时的文字快照
- 扩展不会持续监控，也不读取 Cookie、密码、输入框内容或其他标签页；浏览器内部页与本地文件不会发送
- 浏览器凭据由随机 Token 保护，Windows 与 macOS 使用系统安全凭据库；撤销连接后旧扩展必须重新配对
- Agent 的 `browser_read` 只读取用户已经主动发送的最近页面；v1.6 在此基础上增加需要双重确认的受控操作，仍不提供登录、购买或静默控制浏览器的能力

### MCP Streamable HTTP

- 可以保存最多 20 个 MCP Streamable HTTP 服务器，执行 `initialize` 和 `tools/list` 并显示服务器工具清单；首批兼容使用初始化会话的 2025-03-26 至 2025-11-25 协议版本
- 远程服务器必须使用 HTTPS；明文 HTTP 只允许 `localhost`、`127.0.0.1` 或 `::1`
- 可选 Bearer Token 只进入 Windows 凭据管理器或 macOS 钥匙串，不进入 `localStorage`、日志、JSON 备份或 GitHub
- 工具会根据服务器 annotations 与名称显示“只读、需确认或高风险”提示，但未知工具一律按可能写入处理
- 连接中心手动调用会显示服务器、工具名与 JSON 参数预览并逐次确认；v1.6 进一步让 Agent 自动使用明确只读的工具，写入与删除仍逐次确认
- 付款、购买、下单和资金转移类工具在 Kardii 中直接禁用，不能通过确认框放行
- 本机日志只记录服务器名、工具名、成功状态、耗时和错误摘要，不记录 Token、完整参数或结果，可随时清空
- MCP 返回结果与网页、文件一样属于不可信资料，不能改变 Kardii 的系统规则或授权边界

## v1.4 Google / Microsoft 只读连接

- Google Workspace 使用系统浏览器 OAuth 2.0、PKCE S256、随机 `state` 与随机本机回调端口，读取最近 Gmail、Google Calendar、Drive 和 Sheets 项目
- Microsoft 365 使用公共客户端授权码流程与 PKCE，读取最近 Outlook、Calendar，以及 OneDrive 根目录和近期一级文件夹中的项目与在线 Excel；SharePoint 读取可单独勾选

### 首次配置 OAuth 应用

Kardii 不内置属于开发者个人的 OAuth Client ID。首次连接前，需要在对应服务商后台创建一个桌面/公共客户端：

1. Google Cloud：配置 OAuth 同意屏幕，启用 Gmail、Google Calendar、Google Drive 与 Google Sheets API，创建“桌面应用”OAuth 客户端；把 Client ID 和控制台提供的可选 client secret 填入 Kardii。

3. 登录时 Kardii 会打开系统浏览器。授权完成后回到工作台；访问令牌和刷新令牌不会显示在页面或写入备份。

## v1.0 Agent

Kardii v1.0 在原有桌宠、聊天、长期记忆、知识库和工作台之上加入通用 Agent 中枢。它不预设用户的职业或工作内容，可以处理生活、学习、研究、创作和受控电脑任务。

### Agent 任务中心

- 在聊天框中切换普通聊天与 Agent 模式
- Agent 先理解目标并生成 2–8 步可检查计划，再逐步执行
- 每次工具返回结果后重新判断下一步，而不是一次生成固定答案
- 独立任务中心显示当前动作、计划进度、AI 判断次数、工具调用次数和完整活动记录
- 支持暂停、继续、取消、失败重试和关闭应用后恢复
- 每个任务默认最多执行 12 步，可在 3–20 步之间调整，防止无限循环和意外费用
- 连续执行达到 10 分钟会自动暂停，用户检查后可以继续
- 任务、过程与最终结果保存在本机，并包含在完整备份中

### v1.0 工具与权限

- 自动只读：公开网页搜索、本机知识库检索、已确认长期记忆检索
- 逐次确认：选择并读取文本文件、读取或写入剪贴板、打开网页、运行受限终端命令
- 资料不足时 Agent 会暂停并向用户提出一个明确问题
- 文件、网页摘要、剪贴板和终端输出均按不可信资料处理，不能覆盖 Agent 安全规则
- 删除数据、系统提权、付款、自动发送消息和静默浏览器操作不在 v1.0 Agent 工具范围内

### 通用化调整

- 新用户的工作台不再预置任何行业、客户、市场或平台示例数据
- 工作台实体表单保持空白，不在输入框中显示特定业务示例
- 商务工作台作为可选模块保留，不再决定 Kardii 的整体定位
- 聊天自动写入商务工作台默认关闭，需要时可在工作台侧栏手动开启
- 文件分析与知识库问答改为通用资料分析，不假设文件属于企业或商务场景

### 个性与长期记忆

- 温柔治愈、黏人撒娇、元气小太阳、傲娇腹黑、毒舌吐槽、冷面管家六种性格
- 自定义 Kardii 对用户的称呼和相处方式
- 最多 20 条由用户确认保存的长期记忆
- 聊天中使用“记住：”“查看记忆”“忘记：”管理记忆
- 识别可能值得保存的信息并询问，未经确认绝不保存
- 使用迁移码在不同电脑之间复制个性和长期记忆
- 将个性、记忆和全部聊天会话导出或导入为完整 JSON 备份
- 迁移码和备份均不包含 API Key

### 用户授权的桌面工具

- 读取用户在系统选择器中亲自选中的 UTF-8 文本或代码文件
- 单次读取或写入系统剪贴板文字，不在后台持续监控
- 使用系统默认浏览器打开经过检查的 `http` / `https` 地址
- 在 Windows `cmd` 或 macOS `zsh` 中运行用户输入并再次确认的单行命令
- 每次工具操作都显示具体内容，仅允许一次，不提供永久授权
- 拒绝常见的删除数据、修改系统、提权和多行命令，运行超过 20 秒自动终止
- 文件、剪贴板与终端结果只在用户发送下一条问题时交给当前选择的 AI
- 本机保存最近 30 条工具执行记录，可随时清空，不加入备份

### 安全与隐私

- DeepSeek 与 Gemini API Key 不写入源码、配置文件、备份或 GitHub
- Windows 使用系统凭据管理器保存 API Key
- macOS 使用系统钥匙串保存 API Key
- 聊天、记忆、工作台与 Agent 数据只保存在当前电脑的 SQLite 数据库与兼容缓存中；不会自动同步到服务器
- 使用 DeepSeek 或 Gemini 时，对话内容会发送至当前选择的云端服务；使用 Ollama 时只发送至这台电脑上的本机服务
- 为了避免误连外部服务器，v0.7 的 Ollama 地址只允许 `localhost`、`127.0.0.1` 或 `::1`
- 语音转文字完全在本机执行，原始录音不保存、不上传
- 离线语音模型仅在用户点击下载后从 sherpa-onnx 官方发布地址获取
- Agent 只会自动使用公开搜索、知识库和长期记忆等只读工具；本地读取、写入、打开网页与终端命令必须逐次确认
- 工具返回内容按不可信资料处理，不能覆盖 Kardii 的系统安全规则

## AI 与语音设置

1. 单击 Kardii 打开聊天窗口，再点击右上角齿轮。
2. 选择 DeepSeek、Gemini、Ollama 或 Codex。
3. DeepSeek/Gemini：粘贴对应服务的 API Key，保存后点击“测试连接”。
4. Ollama：先在电脑上安装并运行 Ollama、下载至少一个模型，再点击“刷新模型”和“测试本机连接”。
5. Codex：先安装官方 Codex CLI，再点击“使用 ChatGPT 登录”；在浏览器完成官方登录后返回 Kardii 刷新并测试连接。
6. 连接成功后关闭设置即可聊天；顶部标签会显示当前使用的服务。

第一次使用语音时，在同一设置面板点击“下载离线模型”。下载和加载完成后，聊天输入框旁会出现可用的麦克风按钮。自动朗读保持默认关闭，需要时再在设置中打开。

不要把 API Key、Codex 登录文件或浏览器登录信息提交到仓库、截图公开或发送给其他人。

## 当前限制

- v1.2 的 Codex app-server 需要本机 Codex CLI 支持对应稳定协议；不支持时会回退到一次性 `codex exec`，回退模式不会逐字显示。
- 工作台图片与扫描件需要用户主动点击并使用 Gemini 识别；复杂版面、批注和逐元素版式还没有完整还原。
- JSON 完整备份会保存文件索引、提取文字和分析成果，不会重复嵌入 `workbench-files` 中的二进制原件；跨电脑迁移原件仍需单独复制。
- ChatGPT 订阅并不等于通用 OpenAI API 额度；Kardii 的 Codex 模式使用 Codex/ChatGPT 账户当时可用的模型和用量限制。
- Ollama 需要用户另行安装；较大的本机模型会占用更多硬盘和内存，速度取决于电脑配置。
- MCP 服务器仍需用户手动添加并测试，尚未提供第三方工具市场或自动推荐安装。
- 最多同时执行 3 个 Agent 任务；更多任务会排队，并且并行任务仍共享当前 AI 服务的额度、速率限制和电脑资源。
- 后台自动化依赖 Kardii 进程留在系统托盘；完全退出、电脑关机或休眠时不会执行，也没有云端服务器执行端。
- 当前语音输入为“录完后识别”，尚未加入持续监听或唤醒词。
- 企业微信文档正文读写当前覆盖 `doc` 与 `smartpage`；在线表格、智能表格、PPT、脑图等搜索结果暂时从企业微信客户端打开。
- 企业微信机器人依赖 Kardii 进程与当前选择的 AI 服务保持可用，不是独立云端机器人服务。
- 手机企微远程 Agent 只执行已绑定账号二次确认的只读分析任务；授权目录只读和 MCP 白名单都必须预先在电脑端配置。不等同于远程桌面，不能控制鼠标键盘、运行终端、读取任意文件或代替用户完成外部写入。
